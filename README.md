# 映画管理アプリ（Movie Management App）

## 概要

Pythonで開発した、映画の登録・管理を行うCUI（コマンドラインインターフェース）形式の映画管理アプリケーションです。

映画のタイトルや監督、ジャンル、公開年、評価などを登録し、自分が鑑賞した映画を管理することができます。

また、登録した映画の検索や編集、削除、並べ替えなどの機能を実装しています。

## 開発目的

Pythonの基礎文法や関数、リスト、辞書、ファイル操作、例外処理などの理解を深めることを目的として開発しました。

また、機能の実装だけでなく、入力値の検証やデータの保存、ユニットテストなども取り入れ、実用的なアプリケーションの開発を経験することを目指しました。

## 主な機能

### 1. 映画の登録
以下の情報を入力して映画を登録できます。

- 映画ID
- タイトル
- 監督
- ジャンル
- 公開年
- 評価

### 2. 映画一覧の表示
登録されている映画の情報を一覧で表示できます。

### 3. 映画の検索
映画のタイトルを指定して検索できます。

- タイトルの部分一致検索
- 大文字・小文字を区別しない検索

### 4. 映画情報の編集
登録済みの映画情報を編集できます。

### 5. 映画の削除
登録済みの映画をIDなどを利用して削除できます。

### 6. ジャンルによる絞り込み
指定したジャンルに該当する映画を表示できます。

### 7. 映画の並べ替え
公開年や評価などを基準に映画を並べ替えることができます。

### 8. データの保存
映画の情報はJSON形式で保存します。

アプリケーション起動時にJSONファイルからデータを読み込み、映画の登録・編集・削除を行った際にデータを保存します。

## 実行方法

### 1. リポジトリをクローン

```bash
git clone <リポジトリのURL>
```

### 2. プロジェクトのディレクトリに移動

```bash
cd movie-management-app
```

### 3. アプリケーションを起動

```bash
python3 main.py
```

起動後、画面に表示されるメニューに従って操作してください。

## テスト方法

Python標準ライブラリの`unittest`を使用して、各機能の動作を検証しています。

以下のコマンドでテストを実行できます。

```bash
python3 -m unittest -v test_main.py
```

### 主なテスト項目

- JSONファイルが存在しない場合の動作
- JSONファイルの読み込み処理
- 不正なJSONデータに対する処理
- 不正なデータ形式に対する処理
- 映画の登録処理
- 映画の編集処理
- 映画の削除処理
- 映画の検索処理
- ジャンルによる絞り込み処理
- 映画の並べ替え処理
- データの保存処理

テストでは`unittest.mock`などを利用し、入力値やファイル操作を制御することで、各機能を個別に検証しています。

## データ形式

映画のデータはJSON形式で管理しています。

データの例：

```json
[
    {
        "id": 1,
        "title": "インセプション",
        "director": "クリストファー・ノーラン",
        "genre": "SF",
        "year": 2010,
        "rating": 5
    }
]
```
